# Auto-messaging system with specialized GPT agents

## Overview

This Telegram bot includes an auto-messaging system that periodically generates and sends messages to users. Each message type is produced by a specialized GPT agent. If a user replies to an auto-message, the same agent continues the conversation using the saved context.

## Key files

1. `src/utils/auto_messaging_config.json` — auto-messaging configuration (message types, schedules, prompts, topics)
2. `src/utils/auto_messaging_generator.py` — message generation using the orchestrator and agents
3. `src/utils/auto_messaging_scheduler.py` — scheduling and delivery of messages
4. `src/db/models.py` — database models for auto-messaging and reminders
5. `src/bot/telegram_bot.py` — Telegram bot integration (`/auto_messages`, delivery, and replies)

## System capabilities

### 1) Topic-specific messages generated by specialized agents

Each auto-message type is associated with an agent type, for example:

- Health tips (`medical_knowledge`)
- Memory exercises (`memory_support`)
- Emotional support (`emotional_wellbeing`)
- Caregiver support (`family_support`)
- Nutrition tips (`nutrition_hydration`)

### 2) Flexible scheduling

Message schedules support:

- **Daily** delivery at a specified time
- **Weekly** delivery on a specified weekday and time

### 3) Context-aware follow-ups

When a user replies to an auto-message, the system:

- Identifies that the reply is connected to the previous auto-message
- Routes the reply to the same agent that generated the original message
- Continues the conversation using the agent context stored in the database

### 4) Basic management via Telegram

Users can:

- View scheduled auto-messages with the `/auto_messages` command
- See which agent is responsible for each message type

## Auto-messaging configuration

The `src/utils/auto_messaging_config.json` file defines each message type. Example:

```json
{
  "auto_messages": [
    {
      "id": "health_tips",
      "name": "Health tips",
      "agent_type": "medical_knowledge",
      "schedule": "daily",
      "time": "09:00",
      "template": {
        "system_prompt": "...",
        "user_prompt": "Create a helpful health tip on the topic: {topic}."
      },
      "topics": ["nutrition and hydration", "sleep routine", "stress management"],
      "media_type": "text"
    }
  ]
}
```

## How it works (high level)

1. On startup, the bot schedules auto-messages for users based on `auto_messaging_config.json`.
2. The scheduler periodically checks whether any messages are due.
3. When a message is due:
   - A random topic is selected from the configured list
   - The correct agent generates the message
   - The message is delivered to the user
   - Context metadata is stored for possible follow-up replies
4. When the user replies:
   - The system routes the reply to the same agent
   - The agent produces the next response, continuing the conversation

## Data storage

The system typically stores:

- `telegram_users` — Telegram user profiles and metadata
- `auto_message_schedules` — scheduled and delivered auto-messages
- `conversations` — agent conversations (for follow-ups and context)

## Cleanup

To avoid unbounded growth:

- Old in-memory contexts are cleaned up (see `AutoMessagingGenerator.cleanup_old_contexts`)
- Old schedule records can be cleaned up based on retention policy (implementation-specific)
